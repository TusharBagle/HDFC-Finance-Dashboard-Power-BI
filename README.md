# 🏦 HDFC Bank Branch Performance Dashboard - Power BI Project

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of HDFC Bank's branch operations, including deposits, loans, transactions, branch performance, target achievement, and regional performance. The report enables users to monitor key banking KPIs, identify business trends, compare branch performance, and make data-driven decisions using interactive filters and dynamic visualizations.

---

# 📊 Dashboard Pages

## 🏠 1. Branch Performance Dashboard

### Purpose

Provides a complete overview of branch performance, transaction activity, and revenue across the branch network.

### Key KPIs

* Total Branches
* Total Transactions
* Average Transaction Value
* Best Performing Branch

### Visuals

* KPI Cards
* Revenue by Branch Hierarchy
* Transaction Type Distribution
* Branch Network Performance Map
* Monthly Transaction Trend
* Branch Performance Table
* Interactive Slicers
